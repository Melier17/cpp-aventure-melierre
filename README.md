# Aventura Melierre

RPG de aventura y supervivencia 2D desarrollado en C++17 con raylib.

## Estado actual

Este repositorio se encuentra en una etapa temprana de prototipo. La base inicial incluye una ventana de raylib y movimiento sencillo del jugador.

## Objetivo de la v0.1

- Perspectiva top-down 2D.
- Exploración de un mapa de prueba.
- Movimiento del jugador en ocho direcciones.
- Cámara que siga al jugador.
- Colisiones básicas con obstáculos.

## Tecnologías

- C++17
- raylib 5.0
- CMake

Las mecánicas de combate, inventario, supervivencia, mazmorras y multijugador están planificadas, pero todavía no implementadas.
